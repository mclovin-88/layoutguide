# Layout Guide

เว็บแอปช่วยไกด์การจัดวางภาพโฆษณาในหลายไซส์ จากภาพต้นแบบภาพเดียว ใช้ฟรี ทำงานในเบราว์เซอร์ทั้งหมด ไม่ส่งภาพออกจากเครื่อง ไม่ใช้ AI

## วิธีใช้
1. ลากภาพต้นแบบเข้ามา (JPG, PNG, WebP, PSD) หรือกดวางจากคลิปบอร์ด
2. (ไม่บังคับ) แตะบนภาพเพื่อกำหนดจุดสำคัญ เช่น หน้าพรีเซนเตอร์หรือโลโก้
3. เลือกไซส์ที่ต้องการ หรือเพิ่มไซส์เอง
4. กด **สร้างไกด์** แล้วเซฟทีละไซส์ หรือเซฟทั้งหมดเป็น ZIP

## การจัดวางอัตโนมัติ
- หาบริเวณที่มีรายละเอียดมาก (ขอบ, ตัวหนังสือ, สีสด) แล้วตัดให้เนื้อหาสำคัญอยู่ในกรอบ
- ถ้าตัดแล้วเสียเนื้อหาเกินค่าที่ตั้ง จะย่อภาพแล้วเติมพื้นหลัง (เบลอ / สะท้อน / ยืดขอบ / สีเดียว)
- ปรับรายไซส์ได้: เลือกตัดเต็มกรอบ / ครบทั้งภาพ และกดปุ่มเลื่อนเพื่อลากปรับตำแหน่ง

## เส้นไกด์
Safe zone, กริด 1/3, ขอบภาพต้นแบบ + พื้นที่ที่ถูกเติม, จุดสำคัญ — เลือกได้ว่าจะใส่ในไฟล์ที่เซฟหรือไม่

## โฮสต์
ไฟล์เดียว `index.html` อัปขึ้น GitHub Pages ได้ทันที
