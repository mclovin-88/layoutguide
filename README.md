# Layout Guide

ไกด์จัดวางโฆษณา 7 ไซส์จากภาพต้นแบบภาพเดียว ด้วย Gemini (ฟรี) — ใช้โควตา Gemini แค่ 1 ครั้งต่อ 7 ไซส์

## วิธีใช้
1. ใส่ภาพต้นแบบ แล้วเลือกไซส์ (16:9, 1:1, 9:16, 4:5, 2:1, 8:1, 3:16)
2. กด **ก๊อปแผ่นงาน + เปิด Gemini** → ใน Gemini กด Ctrl+V แล้ววางคำสั่งที่เว็บให้ → ส่ง
3. คลิกขวาภาพผลลัพธ์ใน Gemini → Copy image → กลับมากด Ctrl+V ที่เว็บ
4. เว็บหาเส้นกรอบชมพูและตัดแยกเป็นไฟล์ขนาด px ตรงสเปก · ปรับกรอบตัดได้ · เซฟทีละไฟล์หรือ ZIP

ตัวนับมุมขวาบนนับครั้งที่ใช้ผ่านเว็บนี้ต่อวัน (Gemini ไม่เปิดให้เว็บอื่นอ่านโควตาจริง)

## โฮสต์
ไฟล์เดียว `index.html` บน GitHub Pages
