# Layout Guide

เว็บแอปช่วยไกด์การจัดวางภาพโฆษณาหลายไซส์ จากภาพต้นแบบภาพเดียว ใช้ฟรี ทำงานในเบราว์เซอร์ทั้งหมด ไม่ส่งภาพออกจากเครื่อง

## วิธีใช้
1. ใส่ภาพต้นแบบ (JPG, PNG, WebP)
2. เลือกชิ้นส่วน (โลโก้ / หัวข้อ / ข้อความล่าง / พรีเซนเตอร์ / อื่นๆ) แล้วลากกรอบบนภาพ
3. เลือกไซส์ที่ต้องการ หรือเพิ่มไซส์เอง
4. กด **สร้างไกด์** — แต่ละชิ้นถูกจัดวางใหม่ตามกฎของกลุ่มสัดส่วน (แถบยาว / แนวนอน / สี่เหลี่ยม / แนวตั้ง / เสาสูง)
5. ปรับรายไซส์ได้: กดปุ่มเลื่อน แตะชิ้น แล้วลากหรือย่อ/ขยาย
6. เซฟทีละไซส์ หรือทั้งหมดเป็น ZIP

## ตัดชิ้นส่วนด้วย AI
- พรีเซนเตอร์ / อื่นๆ: ตัดตามรูปร่างด้วย ISNet
- หัวข้อ / ข้อความล่าง / โลโก้: เติมพื้นหลังก่อน แล้วเทียบกับภาพเดิมเพื่อได้ตัวหนังสือโปร่งใส
- ตำแหน่งเดิมของชิ้นที่ย้าย: เติมด้วย LaMa
- ครั้งแรกโหลดโมเดล ~180MB (เก็บไว้ในเครื่อง) · ใช้บนคอมพิวเตอร์ แนะนำ Chrome / Edge

## พื้นหลัง
- ยึดความสูง: ไซส์ที่กว้างกว่าต้นแบบจะเห็นพื้นหลังแหว่งด้านข้าง (PNG โปร่งใส) ไว้ต่อฉากทีหลัง
- ตำแหน่งเดิมของชิ้นที่ย้าย: เติมสีรอบๆ / เจาะออก / คงไว้
